# Estimation Arena

Jogo educativo e interativo para praticar estimativas ágeis com Story Points, avaliar incertezas e planejar Sprints.

## Como executar localmente

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador atualizado.
3. Não é necessário instalar dependências, configurar servidor ou usar banco de dados.

## Publicar gratuitamente com GitHub Pages

1. Crie um repositório no GitHub, por exemplo `estimation-arena`.
2. Envie o arquivo `index.html` e este `README.md` para a raiz do repositório.
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`; clique em **Save**.
6. Aguarde a publicação. O GitHub exibirá o endereço público do jogo na seção **Pages**.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro

## Sobre o jogo

O jogador estima histórias de usuário usando a sequência de Story Points (1, 2, 3, 5, 8, 13 e 21), recebe eventos inesperados, revisa suas estimativas e monta uma Sprint com capacidade de referência de 30 pontos.

> Os valores de Story Points são referências didáticas para a dinâmica do jogo. Na prática, equipes devem estimar de forma relativa e calibrar sua escala conforme o contexto do projeto.
